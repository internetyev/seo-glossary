## (b) Discrepancies

| Term | Glossary meaning | Vendor and vendor meaning in your words | What you propose |
|---|---|---|---|
| featured snippet | the answer box above the organic results (Ukrainian: розширений сніпет) | Ahrefs and Moz define featured snippet as the zero-position answer box, and rich snippet as search results enhanced by structured data; Semrush claims SERP features are the same as rich snippets | The glossary assigns the Ukrainian translation розширений сніпет to featured snippet. Propose updating the Ukrainian translation of featured snippet to виділений опис (or блок з відповіддю), and reserving розширений сніпет for rich snippet. |
| historical data | the ranking and click record a site accumulates on a topic over time | Semrush defines historical data as multi-year archived keyword and domain performance records preserved in SEO tool databases | Keep the semantic SEO definition in section 2; in reporting contexts, clarify that tool historical data refers to provider database archives. |
| bridge | the contextual link from an Outer page into its Core cluster | Ahrefs defines bridge page as an affiliate doorway page created purely to redirect users to an affiliate link | Retain the Koray semantic SEO definition for bridge in section 2; treat affiliate bridge pages as doorway pages. |
| spam score | a provider spam estimate for a domain (Ahrefs is_spam is incomplete) | Moz defines Spam Score as its proprietary 0-100% penalization risk metric calculated using 27 machine learning flags | Keep the generic definition in section 4, but note that Spam Score originated as Moz machine learning metric, distinct from Ahrefs boolean flag. |
| SERP features | snippets, PAA, video, images, local pack, AI Overview and the rest | Semrush equates SERP features with rich snippets in its glossary | Uphold the glossary broader umbrella definition and reject Semrush equation of SERP features with rich snippets. |
| relevance | topical closeness of a page to a query | Moz specifies that in local search, relevance is one of Google three core ranking pillars alongside distance and prominence | Retain the broad definition in section 2, and recognize the three local ranking factors (relevance, distance, prominence) in local search contexts. |
